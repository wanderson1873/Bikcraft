## 📌 About

Home, about, products, portfolio and contact pages, with a slideshow, a mobile menu and a contact form powered by PHPMailer. Built in Origamid's **Web Design** course.

## 🧠 What I practiced

- **Responsive layout** for a multi-page site, from a design file.
- **Small JavaScript plugins** for the slideshow, animations and the contact form.
- **Sending a form by email** with PHP and PHPMailer.

## 🚀 Run locally

```bash
git clone https://github.com/wanderson1873/Bikcraft.git
```

Open `index.html` in a browser, or serve the folder and open `http://localhost:8080`:

```bash
cd Bikcraft
python -m http.server 8080
```

The contact form needs a PHP server with mail configured.
